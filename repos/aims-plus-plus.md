AIMS++ 是一个非官方的第三方浏览器插件（Edge / Chrome），为香港城市大学的 AIMS 换上简洁、现代的新设计，并可以用英文、繁体、简体或双语对照浏览各个页面。所有改动只在你自己的浏览器里进行，不发送任何数据、不代你操作；本项目并非由香港城大制作、维护或认可，译文仅供参考，一切以 AIMS 上的英文原文为准。

## 功能

- **全站新设计**：香港城大品红色标题区、分组菜单、对齐的表格与资料卡，支持深色模式
- **成绩与课表**：成绩页顶部显示 GPA 和学分摘要；每周课表按课程配色，并标出今天
- **双语对照**：每页右上角可切换英文 / 繁体 / 简体，开启双语后每一行下方都有译文
- **离线翻译**：内置约 1,300 条 AIMS 用语的词典，页面文字不会发送到任何翻译服务
- **账户安全**：不发请求、不点击、不提交表单，也不改动表单内容；只申请 `storage` 权限
- **一键还原**：在工具栏关闭插件后，原版 AIMS 立即恢复
- **安装**：从 [GitHub Releases](https://github.com/LENSFORGET/aims-plus-plus/releases/latest) 下载 ZIP，在 Edge 或 Chrome 的扩展管理页面开启开发者模式后加载，详细步骤见[项目网站](https://lensforget.github.io/aims-plus-plus/#install)
