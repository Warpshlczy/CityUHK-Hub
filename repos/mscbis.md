BIS Navigator 是面向香港城市大学 MSc Business Information Systems 学生的中文信息与经验导航，帮助新生和在读同学了解专业方向、查阅课程资料、规划选课并找到常用校园与学习资源。

项目由汪冠彰（Steve）创作并由学生与社区共同建设，2026/27 学年由 DavidYang0429（杨欣睿）负责课程资料核验与日常维护。本站采用 Markdown 与 VuePress 构建，通过 GitHub Pages 提供在线阅读，也欢迎同学补充课程经验、反馈过期信息和失效链接。

本站为学生与社区维护的非官方指南，不代表学校官方立场。培养方案课程池不等于当期实际开课，课程开设、教师、名额、考核与学校政策请以当期官方信息为准；历届学生评价仅供经验参考。

## Features

- MIS 与 FIT 专业方向介绍，以及 2026/27 培养方案必修与选修课程池。
- 共享选修与跨分流课程索引，保留历史课程归类和适用学年说明。
- 课程资料、历届课程评价、学习经验与选课流程。
- 课表规划和 CityU Schedule Planner 使用说明。
- Canvas、CityU Portal 与校内信息技术服务指南。
- 常用学习资源，以及基于 GitHub Discussions 的课程补充与社区讨论。
