# 2026-10-10 — README 顶部图标排版修复

## 问题
README 头部图标显示错乱。根因是 `0f407ea`（"修改了logo"）把徽章改写成一图一行，同时：
1. `?a=1\&b=2` 里的 `\&` 转义符被写进 URL，导致 shields.io 查询参数全部失效（徽章退化：“deploy-vercel” 变成 “deploy”，“code of conduct” 变成 “code”；for-the-badge 尺寸也从 28px 掉到 20px）。
2. 22 个盾牌徽章各占一行 → 高度不一（CI/PR badge 等）、视觉杂乱。
3. `![CityUHK Hub logo](web/public/cityu.jpg)` 丢了 `width`，1280×1280 的 1:1 内含白边图片被撑满整行，把 `# CityUHK Hub` 标题压挤变形。
4. 该提交还顺手删掉了 `<!-- contributors:start/end -->` 标记，导致 `scripts/update-contributors.mjs` 直接抛错失效。

## 修复
- README：徽章分组为 3 行（6 / 8 / 8），用单空格连接；清除全部 8 处 `\&`→`&`；logo 改回带 `width="240" height="240"` 的 `<img>`；补回 contributors 标记。
- `scripts/update-contributors.mjs`：
  - 替换正则改为 `(${START})([\s\S]*?)(${END})` + `$1...$3`，只替换标记内部。
  - **关键坑**：原写法把标记一起吃掉再补写，一旦不匹配，每跑一次就多留一份标记，README 会被越改越乱。改后已验证三次运行 md5 完全一致（幂等）。
  - 新增 `AVATAR_HEIGHT`，头像显式写 width/height 各 80，保证 1:1 不变形。

## 验证
- 24 个 shields 徽章 URL 全部 HTTP 200，尺寸恢复正常。
- 用 marked + 无头 Edge 渲染截图确认：徽章 3 行整齐、logo 居中、标题正常、12 头像方块排布并自动换行。

## 备注
- README 是 CRLF 行尾，用 Edit 工具匹配多行内容容易失败，批量改动建议走脚本。
- 需要改动 README 顶部区块时，注意 `update-contributors.mjs` 依赖 contributors 标记，不要删除。
